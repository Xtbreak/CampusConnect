# 使用说明

## 图形界面

打开构建后的 `CampusConnect.exe`（Windows）或 `CampusConnect.app`（macOS），填写学号、密码并选择电信、移动或联通。点击“连接校园网”后查询认证状态，离线时立即登录，再查询状态确认。随后检查外网：至少一个外部 HTTPS 检测地址返回 HTTP 200 时显示“网络已连接”；全部失败时提示外网检测失败，并区分认证状态。图形版不主动注销或解绑，也不会仅因外网检测失败而重复登录已认证会话。已有会话不代表新输入的凭据已通过验证。

左侧“设置”、顶部设置菜单或托盘设置菜单可打开偏好设置：

- 断线自动登录：保持后台监测，失败后退避重试。
- 记住密码：Windows 使用 DPAPI；macOS 使用系统钥匙串。
- 开机启动：登录当前用户后启动打包应用，需固定程序位置。
- 启动后自动连接：保存完整账号并记住密码后，下次启动自动连接；凭据不完整时不自动连接。
- 关闭行为：隐藏到托盘或彻底退出，点击“保存设置”后生效。

首次使用时四个开关默认开启；开机启动在首次保存设置或连接时生效。已有保存的个人偏好保持不变。

连接期间可以修改以上偏好并保存，无需先停止连接。关闭断线自动登录后，正在执行的检查会完成，随后停止后台监测；等待下一轮期间关闭则立即结束等待。记住密码、登录启动和关闭行为保存后生效，启动后自动连接用于下次启动。账号、密码和运营商在任务运行期间仍锁定，需要停止任务后修改。

默认关闭窗口会隐藏到托盘；双击托盘图标恢复窗口。托盘或侧栏的“退出程序”始终彻底退出。停止按钮终止网络任务，不注销已有连接，也不能撤回已经到达服务器的请求。

macOS 通过菜单栏图标菜单恢复窗口；安装、登录启动和钥匙串说明见 [macOS 使用与发布](macos.md)。以下 Windows 配置路径及注册表说明不适用于 Mac。

保存设置不会校验账号密码；点击连接时才检查必填项。取消记住密码或清空密码后保存，会删除已保存的密码。

## Windows 笔记本与 Wi-Fi

主界面顶部提供“有线连接 / 无线连接”，替代原设置页的“自动连接 AUST_Student”。默认有线；旧版开启了自动连接 Wi-Fi 的用户会恢复为无线。点击“连接校园网”或设置页“保存设置”时记住选择，运行期间需先停止再切换。

有线模式仅通过有线接口认证，不主动连接或断开 Wi-Fi。无线模式使用已保存的 `AUST_Student` 配置自动连接并认证，可能切换当前 Wi-Fi；首次需在 Windows 手动连接一次并保存同名配置。如果门户路由仍走有线，会暂停并提示拔掉网线或选择有线模式，不自动修改路由、禁用网卡。程序不创建开放热点配置、不打开无线网卡、不修改系统自动连接设置。缺少配置、没有信号或连接失败会给出提示。开启持续监测时，失败后至少隔 60 秒重试；关闭持续监测时只尝试一次。

停止任务不会断开已连接的 Wi-Fi，也无法撤回系统已接受的连接请求。开机全自动使用时，还需开启“开机启动”“启动后自动连接”“断线自动登录”，并保存账号密码及连接模式。macOS 暂不提供模式切换，保留原有流程。

开启“断线自动登录”后，开机尚未联网时保持等待；通过 Wi-Fi 访问门户时仅允许名称完全一致的 `AUST_Student`。连接家庭 Wi-Fi、热点或无法读取无线名称时暂停认证。接口识别失败、VPN/虚拟接口也保守暂停，不发送凭据；必要时关闭 VPN 后重试。部分 Windows 版本读取 Wi-Fi 名称需要允许位置访问，拒绝权限时不会绕过限制。

按到门户 `10.255.0.19` 的实际路由识别接口，而非仅判断是否存在无线网卡；同时插网线时以该路由为准。有线仍沿用认证状态检查。等待期间约每 5 秒检查网络变化（系统查询耗时另计），地址或接口变化后重置失败退避，清理旧连接并提前重新检测；睡眠期间不运行，恢复后继续检查。若切换发生在正在执行的请求中，需要等待该请求结束或超时，停止按钮仍可终止子进程。认证请求发送前再次核对网络，已发出的请求无法撤回。

关闭“断线自动登录”时只检查一次，不会一直等待 Wi-Fi。macOS 本次保持原有门户检查流程，尚未加入 Wi-Fi 名称识别保护。

## 配置与日志

图形版数据存储于 `%LOCALAPPDATA%/MyWatch`。取消记住密码和启动后自动连接并保存，会移除已保存的加密密码。取消开机启动并保存，会移除当前用户 Run 注册表中的 `MyWatchCampusConnect` 启动项。

连接页顶部统一显示当前状态；“查看日志”打开包含 `client.log` 的目录。详细日志按天轮转、保留 14 份，记录请求耗时、状态码、错误分类、重试和停止情况，不记录账号密码或完整认证链接。

## 兼容命令行模式

以下命令在项目根目录、已安装依赖的 Python 环境中执行：

```powershell
python -m scripts.configure_cli
python -m campusconnect.core --check-only
python -m campusconnect.core --login-once
python -m campusconnect.core --no-daily-reconnect
```

配置向导读取 `config/config.example.json`，在根目录生成被 Git 忽略的 `config.json` 和明文 `credentials.json`，仅供旧命令行流程使用。图形界面不需要此步骤。旧配置中的 `token` 是密码字段的历史名称，不是独立票据。

命令行保留原有外网诊断、每日重连与解绑逻辑；不加 `--no-daily-reconnect` 时默认每日 04:00 重连。`--reconnect-once` 会主动注销解绑后再登录，请仅在需要时使用。日志位于配置文件同目录的 `logs/`。

## 适配范围与已知限制

当前适配安徽理工大学有线 Dr.COM 门户，电信 `@aust`、移动 `@cmcc`、联通 `@unicom`。来源为学校门户 `http://10.255.0.19:801/eportal/extern/lgdx/ip/3/pc.js`（2026-09-18 核对）。认证状态来自 `/drcom/chkstatus`；`page_type_data` 返回成功不等于在线。

2026-09-20 核对学校 `extern/lgdx/config.js` 的“无线学生”模板，登录方式为 0，与有线同用 Dr.COM 认证；用户确认无线名称为 `AUST_Student`、登录地址相同。程序复用登录接口，不凭空增加 token 或无线控制器参数。无线成功登录仍需在真实笔记本上验收。

认证接口沿用学校 HTTP 协议，URL 编码不是传输加密。SSID 名称不是密码学身份验证，无法抵御同名伪造热点；请仅在可信校园网络使用。其他学校未验证兼容，未完成三家运营商账号的实际登录验收。
